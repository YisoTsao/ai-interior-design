# ADR-021 夜間氛圍光線（images1）與燈具光源
狀態：接受
日期：2026-09-30
背景：使用者要求 3D 的光線物理呈現與參考圖 images1 一致，並大量增加燈具。images1 的特徵：燈具是主要光源（暖色檯燈、
粉/洋紅 RGB 燈板、LED 燈條、螢幕光）、彩色溢光打在牆與地、光滑深色木地板反射燈光、燈罩等發光體有光暈、明亮窗戶與窗簾、
依建物外框的圓角淺灰底座＋黃色底部燈條光暈、灰色舞台背景、遠側與內牆全高而近側牆移除。

決策：
1. **光線模式**：剖面模型新增 `lighting: 'day' | 'night'`（使用者偏好，預設 night）。day＝ADR-017 的日光（images2）；night＝images1。
   切換時重建 Canvas（光源/材質狀態不殘留）。簡易模式不受影響。
2. **燈具是真實光源**：目錄新增 `light` 規格（kind point/spot/area、lm、發光點、光束角/發光面、方向、是否可投影），物件參數
   `color`（色溫 2700–6500K 或 RGB 預設）與 `dimmer`（0–100%）。新增 11 種燈具（檯燈、壁燈、崁燈、軌道燈、主燈、弧形立燈、
   六角燈板、LED 燈條、直立燈條、螢幕）＋窗簾；既有立燈、吊燈補上光源。
3. **物理量**：lm → cd（點光 I＝lm/4π；聚光依光束立體角）或 nit（面光源 L＝lm/πA）。three.js 以「世界單位＝公尺」計算 1/d²，
   場景單位為 mm → 點/聚光強度 ×1e6；面光源亮度與單位無關。顯示時再乘 `NIGHT.photometricScale`（曝光固定 1.0，
   讓 bloom 門檻與背景都在顯示範圍）；相對亮度與衰減仍是物理的。
4. **固定光源池**：point 12、spot 6、area 8（RectAreaLight），依「光通量 ÷ 與焦點距離衰減」挑選；未使用的槽強度 0 → 光源數量不變，
   不會因增減燈具重新編譯 shader。陰影預算 point 2（立方體貼圖）＋ spot 3；純旋轉時不重算陰影。
5. **自發光**：燈罩/燈板/螢幕/LED 在幾何中自成 group 1，材質顏色＝光色×亮度（夜間 >1 觸發 UnrealBloomPass）。
   夜間互動中只關 AO、保留 bloom（避免旋轉時燈光閃爍）。
6. **夜間牆體**：內牆與遠側外牆全高（接收彩色溢光），近側外牆只留 100 mm 牆腳；掛在被移除牆上的壁掛物（窗簾、壁燈、燈板）只留光不畫燈體；
   沒有天花板時嵌入式天花燈（崁燈、軌道燈）同樣只留光。
7. **窗戶**：全高外牆上的窗＝朝室內的面光源（700 lm/m²，6500K）＋自發光玻璃。
8. **地板**：夜間地板 roughness ≤ 0.14；**不使用明亮的攝影棚環境貼圖**——實測它的菲涅耳反射會蓋過燈光、把深色木頭洗成灰白；
   反光只來自實際燈具的鏡面高光。
9. **底座與舞台**：`buildingFootprint`（core-geometry：牆體聯集外環 → 外擴 → 閉運算＋開運算倒圓角，凸角與凹角都圓）擠出成淺灰底座，
   懸浮於地面；底緣自發光燈條＋地面加法混合光暈；地面為不受光的暈影（等角俯視時整個背景其實是地面）。
10. **G-buffer 與光線模式無關**：clay pass 關掉場景光源與環境，改用固定中性光（AI 渲染輸入一致）。
11. **碰撞**：碰撞判定加入垂直範圍（桌上的檯燈/螢幕不算與桌子重疊）；壁掛物不與家具互判。
12. **自動點綴**加燈：房間沒有天花燈 → ~1.8 m 間距崁燈；床頭櫃→檯燈；辦公桌→螢幕；外牆窗→窗簾。

量測（M2、200 家具＋5 房間，含 25 盞立燈 → 光源池上限生效）：夜間旋轉 60.1 FPS（p95 18.5 ms）。

後果／限制：
- 光度換算比例、bloom、光暈等為目視對照 images1 調整的值；沒有 SSR（螢幕空間反射），地板反光是鏡面高光而非鏡像。
- 光源池上限：同時超過 12 盞點光時，遠離畫面焦點者只保留自發光（不照明）。
- AI 渲染 prompt 的光線描述仍為日光（未依模式切換）→ 待 P6。
