# ADR-019 結構驗證的參考邊緣只取「clay 上看得見的」結構邊緣
狀態：接受
日期：2026-09-30
背景：05 §5 以 G-buffer 結構邊緣 E_g（objectId 邊界 ∪ 深度邊界）計算 recall。在 ai-eval 的 30 個場景上，
結構完全保留的 mock（clay＋輕微雜訊）在 balanced（0.80）只有 96.7% 通過（臥室 90%）。原因是部分 objectId 邊界在 clay 上
沒有明暗差（例如與地板同亮度的地毯、同色家具相接處）——輸出圖不可能出現、任何模型都無法「保留」它們，卻被計入分母。
決策：參考邊緣改為 `E_ref = E_g ∩ dilate(Canny(clay), τ)`（`visibleStructure()`，services/api/src/ai/validation）。
門檻與 τ 不變（ADR-012：門檻以使用者選的嚴格度為準）。
量測（ai-eval，mock，150 次/組）：
| | 修改前 | 修改後 |
|---|---|---|
| ok / balanced 通過率 | 96.7%（P10 0.837） | 100%（P10 0.987） |
| ok / strict 通過率 | — | 100% |
| break_structure / balanced 通過率 | 0%（中位數 0.463） | 0%（中位數 0.441） |
後果：
- 好：消除「不可見邊界」造成的誤判；保留與破壞的分數差距擴大。
- 風險：若 clay 本身對比很低，E_ref 可能過少 → recall 以少量邊緣決定。E_ref 為空時 recall＝1（放行），需在真實供應商評測時觀察；
  必要時加最小邊緣數下限。深度控制路線（B）以深度圖構圖，未來可另加「深度邊界」的獨立檢查（05 §5-5）。
- 門檻仍為〔假設〕、未校準；真實供應商評測後定案。
