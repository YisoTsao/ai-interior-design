# 01 產品需求文件（PRD）

## 1. 願景與定位
在**可編輯的 3D 場景**上，用 AI 生成與原空間**結構一致**的高清效果圖，並理解台灣的裝修習慣。Web 與 Desktop 共用同一套核心。

## 2. 角色（Personas）
| 代號 | 角色 | 目標 | 痛點 | 成功情境 |
|---|---|---|---|---|
| P-D | 室內設計師（主要付費者） | 快速做提案圖給客戶 | 建模慢、渲染排隊、改圖要重來 | 30 分鐘內從平面圖做出 3 種風格效果圖 |
| P-H | 屋主 / 自助裝修者 | 看見裝修後樣子、跟設計師溝通 | 不懂專業軟體 | 上傳建照圖，10 分鐘看到 3D 與效果圖 |
| P-S | 房仲 / 建案銷售 | 為空屋/預售屋做佈置圖 | 實景不存在、外包貴 | 批次為多戶型產出樣品屋圖 |

## 3. 範圍
**In scope（v1）**：平面圖匯入與校正、2D 編輯、參數化 3D、家具擺放、材質、AI 渲染、局部重繪、AI 助理、BOM/估價、匯出、Web + Desktop、點數計費。
**Non-goals（v1 不做）**：施工圖/結構計算、BIM 級精度、即時多人協作（Phase 4）、AR 掃描（Phase 4）、原生手機 App、電商結帳、影片漫遊、管理後台 `apps/admin`、樓梯/挑空、含洞（天井）房間、PostGIS。

## 5. 非功能需求（NFR）
| ID | 類別 | 需求 |
|---|---|---|
| NFR-01 | 效能 | 見規則書 B8（≥50 FPS、Draw call ≤300 等） |
| NFR-02 | 可用性 | API 月可用率 ≥ 99.5%（〔假設〕）；任務失敗率 < 3% |
| NFR-03 | 安全 | OWASP ASVS L2 為目標；金鑰不進前端 |
| NFR-04 | 隱私 | 平面圖/照片加密、可刪除、不用於訓練（預設） |
| NFR-05 | 在地化 | 預設 zh-TW；支援 en；坪/m²/mm 顯示切換 |
| NFR-06 | 無障礙 | 鍵盤可操作主流程；對比 WCAG 2.2 AA |
| NFR-07 | 相容性 | Chrome/Edge/Safari 最新兩版；桌面 Win/macOS |
| NFR-08 | 可維護 | TS strict、核心套件測試覆蓋、ADR |

## 6. 成功指標
- 北極星：**每週完成「匯入→編輯→AI 渲染→匯出」的專案數**。
- 支撐：辨識平均校正次數、渲染結構通過率、重生成率、單圖成本/點數售價比、7 日留存。
