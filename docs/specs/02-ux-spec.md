# 02 UX 規格

## 1. 資訊架構（Sitemap）
```
/ 首頁（登入前：產品介紹；登入後：專案列表）
/projects            專案列表（縮圖、最近編輯、搜尋、建立）
/projects/new        建立：空白 / 上傳平面圖 / 範本
/p/:id/import        平面圖匯入與校正
/p/:id/edit          編輯器（2D/3D 切換）
/p/:id/renders       渲染歷史與比較
/p/:id/share         分享設定
/catalog             資產庫（獨立瀏覽）
/account             帳號、點數、帳單、隱私（匯出/刪除資料）
/s/:token            分享唯讀檢視
```

## 2. 主流程
1. **建立專案** → 選擇「上傳平面圖 / 空白 / 範本」。
2. **匯入與校正**：上傳 → 進度 → 校正模式（低信心元素紅框高亮；面板列出「待確認 N 項」；一鍵「全部直角吸附」；尺度校正必經）→ 確認。
3. **編輯**：2D 畫/改牆 → 3D 檢視 → 從資產庫拖家具 → 材質。
4. **AI 渲染**：擺相機 → 選風格 + 嚴格度 + 解析度 → 送出 → 進度 → 結果（可重生成、局部重繪、比較）。
5. **匯出/分享**。

## 4. 互動規格
| 項目 | 規格 |
|---|---|
| 快捷鍵 | V 選取、W 畫牆、D 門、N 窗、M 量測、Del 刪除、Ctrl/Cmd+Z/Shift+Z、Ctrl/Cmd+D 複製、G 位移、R 旋轉、S 縮放、Tab 切換 2D/3D、Space 暫時平移 |
| 選取 | 2D 與 3D 選取同步；Shift 多選；框選 |
| 數值輸入 | 屬性面板可直接輸入 mm/cm/m（依偏好），Enter 提交為一個 Command |
| 吸附 | 端點>牆線>格線；Alt 暫時關閉；狀態列顯示目前吸附 |
| 3D 相機 | 軌道/平移/縮放；「人視角」高度 1600 mm；儲存相機書籤（供渲染使用） |
| 縮放物件 | 預設等比；顯示鎖頭圖示切換 |
| 警示 | 穿牆/重疊以黃色輪廓與底部訊息，不阻擋（除嚴格模式） |

## 5. AI 相關 UX 規則
1. **預覽再套用**：助理的任何場景變更先以半透明/差異呈現，需按「套用」。
2. **渲染設定**：風格卡片（含縮圖）、結構嚴格度滑桿（自由／平衡／嚴格，附一句白話說明）、解析度（1K 預設）。顯示**預估點數**。
3. **進度**：排隊/生成/驗證/完成四階段；可取消；失敗顯示可理解原因與「重試」。
4. **結果頁**：原始 3D 視角 vs 生成圖並排/滑桿比較；「重生成」「局部重繪」「放大到 4K」「下載」；顯示 AI 生成標示。
5. **結構偏移提示**：驗證不通過而自動降級時，以一行說明「已改用嚴格模式以保持結構」。

## 6. 狀態設計
| 狀態 | 規則 |
|---|---|
| 空狀態 | 專案列表空→大按鈕「上傳平面圖開始」+ 範本；資產庫無結果→建議清除篩選 |
| 載入 | 骨架屏；3D 資源分批載入，先顯示 bounding box 占位 |
| 錯誤 | 說「發生什麼＋可怎麼做」；附 requestId 供回報 |
| 離線（桌面/PWA） | 顯示離線徽章；編輯照常；AI 與同步功能停用並說明 |
| 未儲存 | 自動儲存；儲存狀態顯示於頂欄 |
| 點數不足 | 顯示缺額與購買入口，不送出任務 |

## 7. 設計系統（Design Tokens）
以 CSS 變數 + Tailwind config 落地；支援淺/深色。
```
色彩：--bg #FAFAF7 / dark #14161A；--surface #FFFFFF / #1C1F24；--border #E5E4DF / #2A2E35
      --text #1B1D21 / #ECEDEF；--muted #6B7280 / #9AA0A9
      --primary #2F5D50（森綠）/ dark #6FB39F；--accent #C8863A；
      --danger #C0392B；--warn #D9A21B；--ok #2E8B57
字體：UI「Noto Sans TC」+ system fallback；數字/尺寸「JetBrains Mono」
字級：12/14/16/20/24/32；行高 1.5；間距 4 的倍數（4/8/12/16/24/32）
圓角：6（控制項）/12（卡片）；陰影：1 層淺陰影；動效 120–200ms，尊重 prefers-reduced-motion
```
元件庫：以 Radix UI（無樣式原語）+ Tailwind 自建；Icon 用 lucide。

## 8. i18n 與單位
- 預設 zh-TW，備援 en；文案放 `locales/{zh-TW,en}.json`，禁止硬編碼字串。
- 長度顯示可選 mm/cm/m；面積 m²/坪；日期以使用者時區顯示。
- 微文案語氣：簡潔、口語、不用術語（例：說「牆有點歪，已幫你對齊」而非「已執行 Manhattan snap」）。

## 9. 無障礙
- 所有非畫布控制可用鍵盤操作，焦點可見；Radix 元件提供 ARIA。
- 畫布操作提供等價的「屬性面板數值輸入」與物件清單選取，讓鍵盤/讀屏使用者可完成主要編輯。
- 色彩對比 ≥ WCAG 2.2 AA；狀態不只靠顏色（加圖示/文字）。

## 10. 響應式
桌面優先（≥1280）；平板（≥768）支援檢視與輕編輯；手機（<768）僅提供專案瀏覽、渲染結果與分享檢視。
